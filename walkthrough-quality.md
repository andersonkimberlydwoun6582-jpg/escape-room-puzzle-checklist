# Walkthrough quality notes

A good walkthrough helps a stuck player without flattening the whole game into a list of spoilers.

## Recommended structure

1. Objective summary.
2. Controls and camera notes.
3. Early-game hints.
4. Puzzle-by-puzzle guidance.
5. Full solution path.
6. Code status or verification notes.
7. Troubleshooting for loading, iframe, or platform issues.

## Hint ladder

Use three layers:

- Soft hint: tells the player where to look.
- Strong hint: explains what the clue means.
- Solution: gives the exact action or code.

This keeps the page useful for both casual players and completion-focused players.

[Escape the Alien Prison](https://escapethealienprison.xyz/) is an example of a browser game page where walkthrough and verification sections are useful alongside the playable iframe.
