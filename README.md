# Escape Room Puzzle Checklist

A practical checklist for designing short browser escape games: clue clarity, puzzle pacing, fail states, feedback, and walkthrough support.

For a live browser escape-game example, see [Escape the Alien Prison](https://escapethealienprison.xyz/).

## Contents

- `checklist.md` — design checklist for compact escape and puzzle games.
- `walkthrough-quality.md` — notes for writing useful walkthroughs without spoiling everything at once.
- `test/checklist-smoke-test.mjs` — small text completeness check.

## Who it is for

This resource is for indie web-game creators, classroom game projects, Roblox-style experience designers, and anyone planning a short escape-room loop.
